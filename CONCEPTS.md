# Concepts

## Params

Raw URL search parameters.

Example:

status=active&page=2

---

## Query

Normalized typed server query.

Used internally by loaders.

---

## Screen

Page-specific orchestration layer.

---

## Feature

Reusable business capability.

---

## Suspense island

Independent streaming boundary.

---

## UI-only params

URL params that should NOT invalidate data cache.

Examples:

drawer
mode
expanded

# URL kit transport + RSC-mirror sections

Phase 2.5 implementation notes for the hybrid page.

## What changed

- Added **`platform/url-kit/url-params/`** — pluggable transport (router fallback + shallow adapter).
- Refactored URL hooks (`useUrlFilters`, `useUrlPagination`, `useUrlSorting`, grouping, view resolution) to call **`useUrlParamsTransport()`**.
- Hybrid page wraps **`ShallowUrlProvider`**; chrome imports stay **`@/platform/url-kit/*`** (same as RSC).
- Layout sections mirror RSC composition with commented optional blocks preserved.

## RSC vs hybrid

| Concern | RSC demo | Hybrid demo |
|---------|----------|-------------|
| Transport | Router fallback (no provider) | `<ShallowUrlProvider initialSnapshot={…}>` |
| Pending UI | `NavigationPendingDimmer` | `FetchPendingDimmer` |
| Filter/table sections | RSC async loaders | Client TanStack data props |
| Chrome imports | `@/platform/url-kit/*` | Same |

## listQuery for TanStack

```tsx
// views/demo-hybrid-page/hooks/use-list-query-from-url.ts
const { effectiveParams } = useUrlParamsTransport()
const listQuery = parseListQueryFromSearchParams(effectiveParams)
```

`initialSnapshot` is built on the server in `search-params-to-snapshot.ts` so hydration keys match.

# Step 2.5 — url-kit transport foundation

## What this step introduced

- **`platform/url-kit/url-params/`** — pluggable transport layer (router fallback + shallow adapter).
- Refactored URL hooks (`useUrlFilters`, `useUrlPagination`, `useUrlSorting`, grouping, view resolution) to call **`useUrlParamsTransport()`**.
- Hybrid page wraps **`ShallowUrlProvider`**; chrome imports stay **`@/platform/url-kit/*`** (same as RSC).
- Layout sections mirror RSC composition with commented optional blocks preserved.
- `use-list-query-from-url.ts` derives TanStack `listQuery` from `effectiveParams`.

## What bottleneck it fixed

- **Need for hybrid-specific forks of filter/pagination chrome.** Without a transport seam, hybrid would duplicate FilterToolbar, PaginationFooter, and every URL hook — or maintain parallel import paths.
- **Drift between page-local shallow hook and platform chrome** that still called `router.replace` internally.

## Findings during implementation

- One shared chrome API works for both RSC and hybrid if **transport is the seam** — provider picks adapter, components stay identical.
- This works without **nuqs** for v1: shallow adapter + router fallback cover both modes. nuqs is a reserved adapter slot — replace shallow only; chrome and entity parsers stay stable.
- `initialSnapshot` built on the server (`search-params-to-snapshot.ts`) so hydration keys match client reads on first paint.

## Fixes applied during the step

- Router fallback when no `UrlParamsProvider` is mounted — existing RSC behavior unchanged (`router.replace` + optimistic reads).
- RSC-mirror layout sections with optional chrome blocks uncommented incrementally (Step 2.6 completes remaining chrome).

## Trade-offs and remaining edges

- Not every url-kit surface migrated in this step — pill search, dropdown internals, NL assistant, query-builder hooks landed in Step 2.6 (appendix).
- nuqs deferred — see `platform/url-kit/url-params/adapters/nuqs.ts.placeholder.md`.

### RSC vs hybrid

| Concern | RSC demo | Hybrid demo |
|---------|----------|-------------|
| Transport | Router fallback (no provider) | `<ShallowUrlProvider initialSnapshot={…}>` |
| Pending UI | `NavigationPendingDimmer` | `FetchPendingDimmer` |
| Filter/table sections | RSC async loaders | Client TanStack data props |
| Chrome imports | `@/platform/url-kit/*` | Same |
